Frequently Asked Questions

자주 묻는 질문 (FAQ)

igame의 폐쇄망 배포, 게임 콘텐츠 및 보안 정책에 대한 안내입니다.

인터넷이 없는 폐쇄망(Air-Gapped) 환경에서도 100% 동작하나요?
네, 완벽하게 동작합니다. igame은 단일 Go 바이너리 내에 React 19 웹 포털과 Phaser 게임 엔진 자산을 모두 내장(go:embed)하고 있으므로 외부 CDN이나 인터넷 요청을 일체 보내지 않습니다.
RealmGuard 타워 디펜스 게임의 밸런스는 어떻게 수정하나요?
관리자 콘솔의 [RealmGuard Designer](`/admin/realmguard`)에서 스테이지, 웨이브, 타워 및 적 스탯을 시각적으로 편집할 수 있습니다. `If-Match` 낙관적 락을 통해 안전하게 업데이트되며 승인 정책에 따라 검토 후 배포됩니다.
사내 인증(SSO)과 개인 키 관리는 어떻게 지원되나요?
Keycloak OIDC SSO를 통한 원클릭 로그인을 기본 지원하며, 개발자를 위한 개인 API 키 발급 및 서비스 중단 없는 실시간 Zero-Downtime Key Rotation을 제공합니다.
게임 플레이 결과 텔레메트리는 어떻게 검증되나요?
클라이언트가 자가보고한 전투 텔레메트리는 서버에서 시각, 순서, 누적 점수 일관성을 server_received_telemetry_v1 규칙으로 엄격하게 검증하여 비정상적인 치팅 기록을 사전에 차단합니다.

Ready to deploy?

30초 만에 로컬에서 실행하기

단 4개의 환경변수로 나만의 사내 게임 플랫폼을 즉시 기동하세요.

bash · quickstart.sh
# 1. PostgreSQL 컨테이너 실행
docker compose up -d

# 2. 필수 환경변수 설정 (정확히 4개)
export POSTGRES_DSN='postgres://igame:igame-password@127.0.0.1:5432/igame?sslmode=disable'
export BOOTSTRAP_ADMIN='admin@example.internal'
export BOOTSTRAP_ADMIN_PASSWORD='a-long-bootstrap-password'
export ENCRYPTION_KEY='base64:dfiTZ2U2j5jzkRiopD8Shi9Wj3ydtLatbG5MUEYaTLw='

# 3. igame 서비스 실행
go run ./cmd/igame

# 4. 브라우저에서 http://localhost:8080 접속!
