Frequently Asked Questions

Frequently Asked Questions (FAQ)

Key details about deployment, game customization, and security governance.

Does igame truly run 100% offline without Internet access?
Yes, absolutely. All React 19 web assets, Phaser 3 game engine files, and API endpoints are embedded directly into the Go binary (go:embed), requiring zero external CDN or npm calls at runtime.
How do administrators modify RealmGuard game balance?
Using the [RealmGuard Designer] console (/admin/realmguard), administrators can visually tune stage paths, wave compositions, tower stats, and enemy speeds with optimistic concurrency control (If-Match).
How does enterprise SSO and key management work?
Keycloak OIDC PKCE SSO is supported out of the box. For developer API calls, personal tokens are encrypted via AES-256-GCM with seamless Zero-Downtime Key Rotation.
How are game scores validated against cheating?
RealmGuard clients never report what happened. They submit only the player's recorded inputs, and the server replays the battle against the published content to decide the score itself under server_replay_v1. Defense Series verifies its battle telemetry for chronological ordering, timestamp bounds, and cumulative consistency under server_received_telemetry_v1.

Deploy Locally in 30 Seconds

Launch your self-contained enterprise gaming platform with just 4 environment variables.

bash · quickstart.sh
# 1. Start PostgreSQL container
docker compose up -d

# 2. Set 4 required environment variables
export POSTGRES_DSN='postgres://igame:igame-password@127.0.0.1:5432/igame?sslmode=disable'
export BOOTSTRAP_ADMIN='admin@example.internal'
export BOOTSTRAP_ADMIN_PASSWORD='a-long-bootstrap-password'
export ENCRYPTION_KEY='base64:dfiTZ2U2j5jzkRiopD8Shi9Wj3ydtLatbG5MUEYaTLw='

# 3. Start igame
go run ./cmd/igame

# 4. Open http://localhost:8080 in your browser!
